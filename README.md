# Dialed downloads

Manual J, S and D at altitude, plus free HVAC field look-ups.

## Download

- **Windows:** [Dialed-Setup.exe](https://github.com/TallTeezSteez/dialed-releases/releases/latest/download/Dialed-Setup.exe)

These links always get the newest version. Older versions: [all releases](https://github.com/TallTeezSteez/dialed-releases/releases).

**First time:**
1. Run the installer.
2. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. You only do this once.

Dialed updates itself after that.

More about Dialed, with screenshots: https://draftline-gules.vercel.app/airflow

## How a new version goes out

**Actions > Release > Run workflow.** Leave the version blank for the next number; add a line of "What's new" if you like. It builds and publishes on GitHub's free machines, and installed copies update themselves.

This repo is public so the downloads work for everyone. The app's code is in a private repo and isn't here.
